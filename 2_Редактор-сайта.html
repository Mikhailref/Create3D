Редактор каталога 3D-сайта

Добавляет модели (HTML из конвертера) в HTML вашего сайта и удаляет их. Всё работает в браузере, файлы никуда не отправляются.

1HTML вашего сайта

или перетащите файл сюда

2Добавить модели

Файлы, которые получились в конвертере (*-3d.html). Можно выбрать сразу несколько.

3Модели на сайте ● есть несохранённые изменения

Сначала загрузите HTML сайта.
Добавленные из OBJ модели удаляются полностью. Встроенные (параметрические) модели можно скрыть из каталога и потом вернуть.

4Сохранить

Исходный файл не изменяется: вы скачиваете новую версию и сами решаете, чем её заменить.
