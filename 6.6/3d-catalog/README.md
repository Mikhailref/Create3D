# 3D-каталог: исходники программ

Четыре рабочих файла (их и открывают для работы):

| Файл | Что делает |
|---|---|
| `out/mesurments.html` | редактор размеров: ставит размеры на модель, строит каркас, сохраняет проект |
| `out/Конвертер-OBJ-HTML.html` | конвертер: превращает проект с размерами в модель с ползунками |
| `out/Редактор-сайта.html` | редактор сайта: добавляет модели в каталог и встраивает в сайт движок |
| `out/Ассистент.html` | ассистент: редактор размеров и конвертер в одном окне по шагам, с автоматизацией и отменой |

Эти файлы **собираются** из папки `src/`. Руками их не правят: при следующей сборке правки пропадут.

## Документы

- `ИНСТРУКЦИЯ.md` — как пользоваться функциями и где они находятся в программах.
- `ИСТОРИЯ.md` — что менялось в каждой версии.

## Как продолжить в новом чате

1. Приложите этот архив и напишите, что нужно изменить.
2. Claude распаковывает архив, **сначала пишет тесты**, потом меняет код в `src/`, прогоняет все тесты и собирает файлы.
3. Вы получаете новые рабочие файлы и новый архив. Старые файлы и старый архив заменяете новыми.

## Сборка и проверка

```
python3 build.py                 # собрать четыре файла в out/
python3 tests/run_all.py --fast  # сборка + расчётные тесты (~2 минуты)
python3 tests/run_all.py         # всё, включая случайные и браузерные тесты (~15–20 минут)
python3 tests/run_all.py thread browser_thread   # только названные тесты
python3 pack.py                  # архив для нового чата: dist/3d-catalog-vN.zip
```

Нужны Python 3, Node.js и Playwright с Chromium (для браузерных тестов).

  03-prepare.js          подготовка размеров: соседство вершин, веса, карты осей

  analyze.js             проверка «каких размеров не хватает» (редактор размеров)
  converter-dims.js      размеры из проекта → параметры (только конвертер)

Один и тот же файл движка попадает во все места, где он нужен: правка `04-solver.js` сразу оказывается
в конвертере, в редакторе сайта и в движке, который уходит на сайт. Тест `build_check.py` это проверяет.

## Правила работы

- **Сначала тесты, потом код.** Новый тест должен быть красным до правки и зелёным после.
- После любой правки движка — полный прогон `run_all.py`.
- Каждая новая версия — запись сверху в `ИСТОРИЯ.md`; новая функция или кнопка — описание в `ИНСТРУКЦИЯ.md`.
  Тест `docs_check.py` следит, чтобы каждая функция конвертера была описана, а названные кнопки существовали.
- Правка движка, которую должны получить сайты, — увеличить номер в `src/VERSION`.
  Редактор сайта при пересохранении сайта ставит движок новой версии.
- Старые модели и сайты: открыть модель заново в новом конвертере (или проект в редакторе размеров),
  выгрузить и пересохранить сайт новым редактором.

## Словарь

- **Каркас** — деталь, сведённая к плоскостям по каждой оси (X, Y, Z) и участкам между ними.
- **Плоскость** — координата грани по оси. **Участок** — промежуток между соседними плоскостями:
  стенка, паз, ступень, радиус (цилиндр), резьба. **«Фикс.»** — закреплённый участок, держит свою длину.
- **Размер** — линейный (между двумя плоскостями) или диаметр. У каждого — ползунок и пределы.
- **Замок** — размер меняется только своим ползунком, остальные в него упираются.
- **Фиксатор центра** — при изменении размера его центр стоит на месте, размер растёт в обе стороны.
- **Группа синхронизации** — размеры группы меняются вместе, связь не ломается ни от какого движения.
- **Составной размер** — один ползунок управляет несколькими размерами сразу.
- **Привязка** — длина одного промежутка равна длине другого, умноженной на число. Так резьба держится
  за носитель (по вершинам 1.08, по впадинам 0.92), а круг остаётся симметричным (левая часть = правая).
- **Резьба** — вместо витков: длина зоны и два диаметра (по впадинам и вершинам), жёстко привязанные
  к диаметру носителя (цилиндра или отверстия). Меняется носитель — резьба меняется в той же пропорции.

## Функции

Функции включаются в конвертере галочкой и бывают в двух блоках:

- **Основной блок** — включённая функция уходит с моделью в редактор сайта и работает у посетителя.
- **Тестовые функции** — включённая функция работает только в конвертере; в редактор сайта не идёт,
  но запоминается в файле модели. В редакторе сайта её можно включить для конкретной модели.

**Односторонняя связь.** Если один размер раздвинул другой (паз раздвинул ширину детали), то при
уменьшении первого второй не сжимается обратно: паз 80 → ширина 130 → паз снова 80, ширина остаётся 130,
стенки становятся толще. Исключение: если элементы шли вплотную к грани детали (без зазора),
второй размер следует за первым в обе стороны.
